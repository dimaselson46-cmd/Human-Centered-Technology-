# Human Centered Technology

Landing page sederhana untuk tema layanan kesehatan digital, pendidikan inklusif, dan solusi teknologi yang berdampak langsung pada masyarakat.

## Struktur project

- `index.html` : halaman utama
- `assets/css/styles.css` : file styling utama
- `assets/js/script.js` : logika kecil untuk halaman
- `package.json` : konfigurasi dasar project

## Cara menjalankan

1. Pastikan Node.js sudah terinstal.
2. Jalankan:

```bash
npm install
npm start
```

3. Buka browser ke `http://localhost:8000`

## Catatan

Project ini dibuat dengan pendekatan yang sederhana dan rapi agar lebih mudah dikembangkan dan meminimalkan potensi error di masa depan.
